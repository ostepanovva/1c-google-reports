Внутреннее приложение

1C-Google-Advance-Reports

Приложение для автоматизации обмена данными между 1С и Google Sheets в рамках внутренних учетных процессов.

Назначение

Приложение используется для обновления рабочих таблиц Google Sheets, распределения информации по авансовым отчетам сотрудников и контроля отсутствующих закрывающих документов.

Приложение не предназначено для публичного использования и используется только уполномоченными пользователями.

Как используются данные

  • данные передаются из 1С в Google Sheets для выполнения внутренних учетных операций;
  • доступ к Google Sheets используется только в объеме, необходимом для работы интеграции;
  • данные не используются для рекламы и не продаются третьим лицам.

Конфиденциальность

Подробная информация об обработке данных приведена в политике конфиденциальности.
