Приложение 1C-Google-Advance-Reports

Дата вступления в силу: 16 сентября 2026 года

1. Назначение приложения

1C-Google-Advance-Reports предназначено для внутренней автоматизации обмена данными между информационной системой 1С и Google Sheets.

2. Какие данные используются

Приложение может получать доступ к данным Google Sheets, необходимым для работы авансовых отчетов и связанных с ними служебных таблиц. В Google Sheets также могут передаваться данные из 1С, необходимые для контроля авансовых отчетов и наличия закрывающих документов.

3. Как используются данные

Данные используются исключительно для:

  • обновления рабочих таблиц Google Sheets;
  • распределения информации по авансовым отчетам сотрудников;
  • контроля отсутствующих закрывающих документов;
  • выполнения внутренних учетных и финансовых процессов.

4. Хранение данных

Данные хранятся в Google Sheets и других сервисах Google, используемых владельцем приложения. Приложение не создает отдельную внешнюю базу данных для хранения данных Google-пользователя.

5. Передача третьим лицам

Данные Google-пользователя не продаются, не используются для рекламных целей и не предоставляются третьим лицам, кроме случаев, необходимых для работы используемых сервисов Google или предусмотренных законодательством.

6. Использование данных Google

Доступ к данным Google используется только в объеме, необходимом для предоставления описанной функциональности приложения. Использование данных, полученных через Google API, осуществляется в соответствии с требованиями Google API Services User Data Policy.

7. Безопасность

Доступ к приложению и связанным таблицам предоставляется только уполномоченным пользователям. Для обмена данными между 1С и приложением используется защищенное HTTPS-соединение и механизм авторизации интеграции.
